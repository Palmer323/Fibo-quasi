# Fibo-quasi
This project provides functions for generating and processing the set of Fibonacci cycles (F-cycles) associated with a quasigroup and the related Pisano spectra (P-spectra) which hold the periods of the F-cycles. It includes a novel approach to testing isomorphism of two quasigroups. 

While this implementation seems generally more efficient than the standard test provided in the LOOPS package, this approach requires further work to eliminate very poor efficiency in a minority of special situations.

The functions are coded in the GAP language and require GAP and the associated LOOPS package to run.

The code is held in file quasifcycles.txt.

Documentation of these functions and examples of their execution is provided in file fibquasigroupdoc.doc.

These functions have accumulated over some time as the result of recreational maths/programming activity. This was initiated through an interest in the length of Fibonacci sequences generated by writing a completed Sudoku as a multiplication table. Generalisation to Latin squares/quasigroups and use of GAP/LOOPS followed.

The approach to testing isomorphism of two quasigroups is to convert each quasigroup to the set of all Fibonacci cycles (I have called them F-cycles) which can be generated from the Cayley table representation and then search for permutations which map one set to the other. The list of periods of the F-cycles for a given quasigroup I have called the Pisano spectrum (P-spectrum) for the quasigroup. (From 'Pisano period' as used in work related to the numerical Fibonacci sequence mod n).

There seem to be two main reasons why this approach is efficient in the majority of cases. 

Firstly, the P-spectrum is isomorphism invariant and is a very effective discriminator. It is used up front in my algorithm to quickly dismiss most non isomorphic cases. 

Secondly, the rate of increase, with the order of the quasigroup, of the  average number of elements in a P-spectrum is surprisingly low (for order 5 quasigroups the average number of items is approx 3.7 and only rises to approx 6.45 for order 20 quasigroups). Given that the elements of a P-spectrum form a partition of the square of the order this means that the maximum period in a spectrum is usually quite a substantial number. The algorithm matches the F-cycles of the two tables in order of length starting with the longest F-cycles.  This means that in
most cases all of the members of the quasigroup are involved in this matching process, and if the matching is successful a permutation is immediately derived. 

Poor performance occurs in some situations where there are multiple F-cycles of the same length and only a subset of members of the quasigroup are involved in any F-cycle. Steiner Loops provide good examples of this.
